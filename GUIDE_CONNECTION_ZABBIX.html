Comment connecter TRANSMAP à votre serveur Zabbix

Étape 1 : Démarrer l'application

Sur votre PC :

  1. Double-cliquez sur : TRANSMAP_Start.bat
  2. Ouvrez votre navigateur sur : http://localhost:5173

Étape 2 : Se connecter au serveur Zabbix

Dans l'interface TRANSMAP :

  1. Cliquez sur "Se connecter à un serveur"
  2. Remplissez le formulaire de connexion

Champ "URL de l'API Zabbix"

Format accepté :

  • http://IP_DU_SERVEUR/zabbix/api_jsonrpc.php
  • http://IP_DU_SERVEUR/zabbix (ajout automatique de /api_jsonrpc.php)
  • https://IP_DU_SERVEUR/zabbix/api_jsonrpc.php (si SSL)

Exemples :

  • http://192.168.1.100/zabbix/api_jsonrpc.php
  • http://zabbix.mondomaine.com/zabbix
  • https://10.0.0.50/zabbix/api_jsonrpc.php

Méthode d'authentification

Option A : Identifiants (classique)

  • Sélectionnez "Identifiants"
  • Utilisateur : votre nom d'utilisateur Zabbix
  • Mot de passe : votre mot de passe Zabbix

Option B : Token API (recommandé)

  • Sélectionnez "Token API"
  • Token : collez votre clé API Zabbix
Pour générer un Token API (Zabbix 6.0+) :
  1. Connectez-vous à l'interface Zabbix
  2. Allez dans : Administration → API tokens
  3. Cliquez sur "Create API token"
  4. Donnez un nom (ex: TRANSMAP)
  5. Copiez le token généré
  6. Collez-le dans TRANSMAP

Vérifier SSL

  • Cochez "Vérifier le certificat SSL" si votre serveur Zabbix a un certificat valide
  • Décochez si le certificat est auto-signé ou invalide

Étape 3 : Tester et se connecter

Cliquez sur "Tester et se connecter"

L'application va :

  • Vérifier la connexion au serveur
  • Détecter automatiquement la version de Zabbix
  • Récupérer la topologie réseau
  • Afficher les hosts, liens et métriques

Compatibilité Zabbix

TRANSMAP est compatible avec TOUTES les versions de Zabbix :
  • Zabbix 5.x : Support complet
  • Zabbix 6.x : Support complet (Token API + Identifiants)
  • Zabbix 7.x : Support complet (Bearer header authentication)

L'application détecte automatiquement la version et adapte :

  • La méthode d'authentification
  • Les appels API spécifiques à chaque version
  • La gestion des tokens

URL de l'API JSON-RPC

L'API Zabbix JSON-RPC est toujours accessible à :

http://VOTRE_SERVEUR/zabbix/api_jsonrpc.php
Si vous ne connaissez pas l'URL exacte :
  1. Ouvrez votre interface Zabbix habituelle
  2. Regardez l'URL dans votre navigateur
  3. Ajoutez "/api_jsonrpc.php" à la fin

Exemple :

  • Interface Zabbix : http://192.168.1.100/zabbix
  • API Zabbix : http://192.168.1.100/zabbix/api_jsonrpc.php

Dépannage

Erreur "Connexion refusée"

  • Vérifiez que l'URL est correcte
  • Vérifiez que le serveur Zabbix est accessible depuis le PC
  • Vérifiez que le port 80 (HTTP) ou 443 (HTTPS) n'est pas bloqué par le pare-feu

Erreur "Authentification échouée"

  • Vérifiez les identifiants ou le token API
  • Vérifiez que l'utilisateur a les permissions nécessaires dans Zabbix

Erreur "Certificate SSL invalide"

  • Décochez "Vérifier le certificat SSL"
  • Ou installez un certificat valide sur le serveur Zabbix

Informations techniques

  • Protocole : JSON-RPC 2.0
  • Endpoint : /api_jsonrpc.php
  • Authentification : Bearer Token (Zabbix 7+) ou Body auth (versions anciennes)
  • Compatibilité : Zabbix 5.x, 6.x, 7.x
